# 아차차(ACHACHA) — 테스트 계획서

- 버전: v1.0 / 작성일: 2026-11-19
- 테스트 기기: 삼성 Galaxy Z Flip4 / Android 16(API 36)
- 테스트 환경: Windows PowerShell, Android Studio, USB 디버깅(필요시)
- 참조: [SPEC.md](../SPEC.md), [IMP-PLAN.md](../IMP-PLAN.md), [API-INTEGRATION.md](API-INTEGRATION.md)

## 1. 테스트 원칙

- **문서/코드 작성 ≠ 테스트 통과.** 모의 테스트, API 실호출, Z Flip4 실기기 결과를 반드시 구분한다.
- '이번 버스 6분 / 다음 버스 20분'의 **20분은 현재 기준**임을 검사한다.
- API에서 둘째 차량이 오지 않으면 '정보 없음', 첫째도 없으면 미운행/정보 없음 등 확인 가능한 상태로 표시한다.
- 알림 정확도, 배터리 소비, 권한·OS 제약을 실제 기기에서 검증한다.
- API 키·위치좌표·휴대전화 식별번호를 테스트 로그나 공개 저장소에 남기지 않는다.

## 3. API 통합 테스트 (실호출 + MockWebServer)

| ID | 입력/상황 | 확인 항목 |
|---|---|---|
| API-01 | 서울 정류장+노선+순번 실조회 | 정류장/방향 일치, 첫째·둘째 제공 가능 여부, 소스/단위 |
| API-02 | 경기 정류장+노선+순번 실조회 | `predictTime1/2`, 차량 ID, `staOrder` 반영 |
| API-03 | 동일 노선의 반대 방향 | 동일 번호가 다른 조회 대상과 혼동되지 않음 |
| API-04 | 둘째 차량 미제공 | null 처리 및 UI 텍스트 정확함 |
| API-05 | API 401/403/서비스 오류 | 인증 오류, 설정 안내, 키 비노출 |
| API-06 | API 429/호출 제한 | 속도 제한, 재시도 백오프, 과다 호출 없음 |
| API-07 | 타임아웃/네트워크 단절 | 이전 ETA 최신 정보로 재사용하지 않음 |
| API-08 | 스키마 변경/잘못된 XML·JSON | 명확한 PARSE_ERROR, 앱 크래시 없음 |
| API-09 | 차량 ID/ETA 역전·누락 | 보수적 정규화/알림 보류 |
| API-10 | HTTPS/인증키 | 안전한 호출 경로, 로그에 키 없음 |
| API-11 | 서울·경기 검색 경계 사례 | 지원 범위와 데이터 출처 명시 |
| API-12 | 40분 감시 호출량 | 제공기관 쿼터 범위 내, 60초 후보 간격 적절성 평가 |

> 실 API 확인 시 실제 사용자 정류장은 공개 테스트 로그에 남기지 않아도 된다. 공식 문서의 샘플 ID 또는 비식별 테스트 ID를 사용한다.

| DEV-10 | 인터넷 오프라인→온라인 | 정합성 유지, 재연결 후 정상 복구 |
| DEV-11 | 진행 중 '감시 중지' 누름 | 서비스와 API 조회 중지, 추가 알림 없음 |
| DEV-12 | '오늘만 종료' 누름 | 당일 추가 알림 없고 미래 반복은 유지 |
| DEV-13 | 날짜/요일 예약 변경 | 시스템 등록 결과가 최신 설정과 일치 |
| DEV-14 | 기기 재부팅 | 미래 예약 복원 정책 확인. 부팅 직후 FGS 무단 시작 없음 |
| DEV-15 | 앱 강제 종료(force stop) | 자동 실행이 중단될 수 있음을 확인하고 안내 정책 기록 |
| DEV-16 | 장시간/여러 감시 세션 | FGS 시간 제한/`onTimeout` 처리 및 누적 사용량 확인 |
| DEV-17 | 접힌 화면·큰 글씨 | 텍스트 잘림 및 설정 조작 문제 없음 |
| DEV-18 | 감시 종료시간 도달 | 서비스·상태 알림 정리, 불필요한 API 조회 종료 |

정확한 알람 특별 접근, 포그라운드 서비스 유형 선언, Android 15+ `dataSync`의 24시간 누적 6시간 제한을 공식 문서와 실제 기기에서 검증한다. 강제 중지 뒤 자동 재시작을 보장하지 않는다.

## 5. 테스트 준비·명령 (환경 준비 후 수행)

```powershell
Set-Location 'C:\mini\achacha-android'
.\gradlew.bat testDebugUnitTest
.\gradlew.bat assembleDebug
adb devices
adb shell getprop ro.build.version.release
adb shell getprop ro.build.version.sdk
adb logcat
```

- Android SDK, JDK, `adb` 등 설치 후 실제 실행한다.
- 가능하면 `connectedDebugAndroidTest`와 UI 자동화 추가.
- 배터리 최적화/Doze 실험은 사용자 기기의 평소 설정에 영향을 줄 수 있으므로 테스트 후 상태를 복구한다.
- 테스트에서 사용하는 개인 교통 경로/주소와 API 키는 로그에서 제거한다.

## 7. 완료/배포 판정 기준

- P0 단위 테스트와 통합 테스트 통과.
- 실 API 서울·경기 도착조회 실증; 둘째 미제공 시 무리 없이 안내.
- Z Flip4에서 즉시 시작, 잠금화면 알림, 최소 한 건의 예약 시작 및 종료 검증.
- 1/3/5분 반복은 실제 측정 결과를 기록하고 보장 수준을 정직하게 설명.
- 알림·실시간 데이터·API 키 누출 이슈가 없는지 확인.
- `assembleDebug` 성공 및 **실제 APK 경로 확인**.
- 실패·제약·미검증 목록을 README와 보고서에 공개하고, '코드 구현'과 '실기기 동작'을 구분.
