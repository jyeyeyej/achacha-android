# Android 16 백그라운드 실행 설계

> 상태: 설계 골격. Android 프로젝트 초기화와 공식 문서 재검증 후 구체 구현을 기록한다.

## 검증 대상

- 즉시 감시 시작과 종료
- 예약 시각의 감시 시작
- 정확한 알람 특별 접근 상태 확인
- Foreground Service 시작 가능 조건과 서비스 유형
- 1·3·5분 재조회 및 반복 알림
- 잠금화면과 앱 비표시 상태
- 재부팅, 시간 및 시간대 변경 후 예약 복원
- 알림 권한 회수와 배터리 최적화 제한
- 종료시각 도달 시 알람·조회·서비스 정리

## 기본 실행 흐름

```text
사용자 설정 저장
  → 다음 단발 알람 예약
  → 예약 Receiver 실행
  → 권한·운영체제 상태 검증
  → 제한된 감시 세션 시작
  → 최신 도착정보 조회 및 알림 판단
  → 수동 또는 자동 종료
  → 다음 반복 예약 계산
```

## 구현 전 결정사항

- Android 16에 적합한 Foreground Service 유형
- 정확한 알람이 반드시 필요한 예약 범위
- 서비스 제한시간보다 짧은 감시 세션의 최대 지속시간
- 삼성 배터리 정책 제한 시 사용자 안내 방식
