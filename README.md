# 아차차 (ACHACHA) 🚌

> **이번 차 탈까, 다음 차 탈까?**  
> 버스 놓치기 전에, 아차차!

**아차차**는 원하는 버스의 **이번 차와 다음 차 도착예정시간**을 함께 알려주는 개인용 Android 버스 알림 앱입니다. 버스 시간을 매번 검색하지 않고도, 지금 서둘러 나갈지 다음 차를 탈지 스스로 결정할 수 있도록 돕습니다.

> **프로젝트 상태:** 기획 및 개발 준비 단계. 아래 기능은 개발 목표이며, 실제 구현·기기 검증 완료를 의미하지 않습니다.

## 왜 만들었나요?

버스가 항상 같은 시각에 오지는 않습니다. 준비를 다 하고 버스 시간을 확인했을 때 이미 '곧 도착'이라면 놓치기 쉽고, 미리 나가면 정류장에서 오래 기다리게 됩니다.

아차차는 사용자가 지정한 시간부터 도착정보를 확인하고, **설정한 도착 전 시점에 이번 버스와 다음 버스를 한 번에 알려주는 것**을 가장 중요한 기능으로 삼습니다.

## 알림은 이렇게 받아요

**상황 A — 다음 버스가 금방 올 때**

> 🚌 **아차차!**  
> 이번 버스는 **6분** 남았습니다.  
> 다음 버스는 **10분 후** 도착합니다.

두 버스의 간격이 약 4분이므로, 조금 더 여유 있게 준비할 수 있습니다.

**상황 B — 다음 버스를 오래 기다려야 할 때**

> 🚌 **아차차!**  
> 이번 버스는 **6분** 남았습니다.  
> 다음 버스는 **20분 후** 도착합니다.

두 버스의 간격이 약 14분이므로, 이번 차를 탈지 판단할 수 있습니다.

*위 시간은 예시이며, 모두 알림을 받은 시점 기준 예상 도착시간입니다.*

## MVP 주요 기능 (개발 목표)

| 기능 | 내용 |
|---|---|
| 서울·경기 버스 검색 | 정류장, 노선, 방향 선택 |
| 두 대 도착정보 | 이번 버스 / 다음 버스 남은 시간, 갱신 시각 |
| 지금 바로 시작 | 필요한 장소에서 즉시 버스 감시 시작 |
| 예약 시작 | 날짜·시각 및 요일별 반복 예약 |
| 자유로운 알림 시점 | 도착 **12분 전, 4분 전** 등 복수 숫자 직접 입력 |
| 반복 알림 | 반복 안 함 / **1분·3분·5분** 간격 선택 |
| 즐겨찾기 | 집·회사·본가 등 자주 이용하는 정류장·노선 저장 |
| 알림 종료 | 수동 종료, 오늘만 종료, 예약 종료시간 |

### 알림 설정 예시

- 감시 시간: 평일 **07:40~08:20** (예시일 뿐 아침에만 제한되지 않음)
- 알림 시점: 버스 도착 **10분 전 + 6분 전**
- 반복 알림: **3분 간격**
- 알림 메시지: **이번 버스와 다음 버스의 최신 도착예정시간 동시 표시**

## 개발 환경

- **플랫폼:** Android 네이티브 앱 (개인용 APK)
- **테스트 기기:** Samsung Galaxy Z Flip4 / Android 16
- **예정 기술:** Kotlin, Jetpack Compose, Android 알림·예약·백그라운드 실행 API
- **데이터:** 서울특별시·경기도 공식 버스 도착정보 API
- **로그인:** 사용하지 않음 (개인용)

> Android 16의 백그라운드 실행 제한, 예약 실행 권한, API 접근 및 조회 한도는 실제 구현과 기기 테스트를 통해 검증합니다.
